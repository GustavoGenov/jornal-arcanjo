# Jornal Arcanjo

> **Portal digital independente de Cultura, Sociedade, Espiritualidade, Memória e Tradições.**

---

## 🏛️ Sobre o Projeto

O **Jornal Arcanjo** é um portal jornalístico focado no lado humano, reflexivo e comunitário da informação:
- **Cultura & Memória:** História, literatura, tradições e patrimônio.
- **Espiritualidade & Filosofia:** Reflexões profundas, diálogo inter-religioso, sabedoria ancestral e bem-estar.
- **Sociedade & Comportamento:** Vida comunitária, cidadania, histórias inspiradoras e fatos locais de Formiga (MG) e do Brasil.
- **Cotidiano & Serviços:** Clima tempo interativo e reflexões astrológicas/horóscopo diário.

---

## 🛠️ Tecnologias

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack, SSR/SSG)
- **Front-end:** React 19, CSS Modules, Design Responsivo de Alta Performance
- **Banco de Dados & Storage:** [Supabase](https://supabase.com/) (PostgreSQL & Object Storage)
- **Monetização:** Otimizado para Ezoic (integração segura via script) e expansão futura para Mediavine
- **Deploy:** [Vercel](https://vercel.com/) com Edge Network global

---

## 🚀 Como Executar Localmente

```bash
# Instalar dependências
npm install

# Configurar variáveis de ambiente
cp .env.example .env.local

# Iniciar servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador.
